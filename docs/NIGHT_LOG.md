## Что нужно от тебя утром

1. **Поставить на телефон**: подключи по USB с отладкой →
   `~/Android/Sdk/platform-tools/adb install -r app/build/outputs/apk/release/app-release.apk`
   (или просто перекинь APK на телефон). При запуске дай «Полный доступ к файлам».
2. **Яндекс**: Сервисы → Войти → открой ya.ru/device, введи код. Затем «Синхронизировать» и «Новые версии?».
   Это единственная часть, которую я не мог проверить вживую (нужен твой аккаунт) — если что-то
   упадёт, пришли текст ошибки из строки статуса.
3. **YouTube на телефоне**: если YouTube доступен только через VPN — включи VPN, либо укажи прокси
   в Настройки → Сеть.
4. **Десктоп**: `./gradlew :desktop:run` — звук там ночью не проверял.
5. Переименовать папку проекта: `mv ~/Projects/xvin_music_player ~/Projects/palimpsest` (после выхода из этой сессии).

- ПК без окна: волна, перезапуск (продолжилась с конца очереди), встряска; смешанная/YouTube/Bandcamp играют. ✔
- Эмулятор ↔ ПК (копия твоих настроек, громкость 0): ПК→телефон (локальный FLAC стримится с ПК), телефон→ПК,
  «забрать» с обеих сторон; анимации сняты на видео. ✔
- Радио: телефон (http-станция + ICY в уведомлении), ПК (поток + название в баре). ✔ Юнит-тесты `:core` зелёные.

**Нашёл по дороге:** каталог radio-browser из твоей сети напрямую часто зависает посреди ответа (похоже на
троттлинг) — теперь он ходит через прокси из настроек, если тот задан.

**Не проверено / от тебя:**

  на телефоне (он «здоровается» раз в минуту) и проверить, что оба в одной сети без изоляции клиентов.
- «Необъяснимые ошибки» на телефоне: явных причин в коде, кроме зацикливания, не нашёл. Если повторится — пришли
  текст из журнала ошибок (Настройки → О приложении → Ошибки, «Скопировать»).
