## Журнал

### 00:10–01:00 — каркас, ядро, приложение
- Gradle (AGP 9.4, Kotlin 2.4, compileSdk 37, minSdk 33), модули `:core` (чистый Kotlin) и `:app`.
- `:core`: эквалайзер (биквады RBJ + лимитер), FFT-анализатор спектра, парсер AutoEQ, LRC, разбор имён файлов
  (под твою структуру `Murglar/Яндекс/...`), сопоставление треков, клиент Яндекс.Музыки (вход по коду, лайки,
  плейлисты, поиск, FLAC через get-file-info + AES-CTR, тексты), YouTube через NewPipe, LRCLIB.
  19 юнит-тестов зелёные. Живой тест: YouTube-поиск и поток работают (через твой прокси), LRCLIB работает.
- `:app`: Room-база, сканер медиатеки, теги через jaudiotagger, Media3-сервис со своим аудиопроцессором
  (EQ, ReplayGain, спектр), стриминг с кешем, загрузки (WorkManager), версии треков, весь UI.
- **Проверено на эмуляторе** на 18 твоих реальных файлах: сканирование (теги, обложки, кириллица),
  воспроизведение FLAC, фоновый сервис, «Открыть с помощью» (находит трек в медиатеке),
  синхронный текст из тега Мурглара с подсветкой строки, визуализатор, цвет из обложки.

### 01:00–01:30 — проверка всего на эмуляторе, исправления

### 01:30–01:50 — новые фичи
- **Волновая форма** вместо полоски перемотки (для локальных файлов; считается один раз, кешируется).
- **Виджет на рабочий стол**: обложка, название, ⏮ ▶ ⏭. Проверено: из полностью закрытого приложения
  кнопка ▶ на виджете продолжила прошлую очередь с того же места.
- **Свайп** по обложке в плеере и по мини-плееру — следующий/предыдущий трек.
- **Ежедневная синхронизация** по Wi-Fi: лайки/плейлисты Яндекса + проверка перезалитых треков;
  опционально — автоскачивание новых лайков (настройки → «Скачивать новые лайки»).
- **M3U-плейлисты** из папки с музыкой подхватываются автоматически (пути с ПК сопоставляются).
- **Лайк в приложении = лайк в Яндексе** (и обратно при синхронизации), автообновление токена.
- Тесты клиента Яндекса на ответах формата реального API (MockWebServer): лайки, подпись get-file-info, плейлисты, лайк.

### 01:50–02:00 — десктоп, эквалайзер по устройствам, офлайн
- **Превью десктопной версии (Linux)**: модуль `:desktop` на Compose Multiplatform, использует то же ядро
  (эквалайзер, спектр, LRC). Запущена на ПК: просканировала твою `~/Music` — 1269 треков за пару секунд.
  Декодирование через ffmpeg → DSP ядра → javax.sound. ⚠️ Звук на ПК ночью не включал — проверь сам:
  `./gradlew :desktop:run` (или `desktop/build/compose/binaries/main/app/palimpsest/bin/palimpsest`).
- **Эквалайзер по устройствам**: у каждых наушников (BT/USB/проводные) может быть свой профиль, переключается сам.
- **Офлайн**: фильтр «Скачанные»; если облачный трек не грузится (нет сети) — плеер сам переходит
  к следующему. Проверено с выключенной сетью на эмуляторе.

### 02:00–04:15 — ещё фичи и вычитка
- Синхронизация лайков Яндекса **узнаёт треки, которые уже есть на телефоне** (MP3 от Мурглара без тега URL)
  и связывает их, а не создаёт облачные дубли — «Скачать все лайки» не будет качать то, что уже есть.
- Умные плейлисты: «Часто слушаю», «Недавно добавленные», «Давно не слушал».
- Скробблинг в ListenBrainz (токен в настройках), прослушивания копятся офлайн.
- Миграция базы v1→v2 проверена на эмуляторе: история сохранилась (важно для будущих обновлений).
- Редактируемая папка загрузок (можно указать `Music/Murglar`).
- Исправлено при вычитке: сканер мог подхватить недокачанный временный файл; загрузка могла
  перезаписать чужой файл; обложка у альбомов Spotify; кнопки таймера сна.

## Что нужно от тебя утром

1. **Поставить на телефон**: подключи по USB с отладкой →
   `~/Android/Sdk/platform-tools/adb install -r app/build/outputs/apk/release/app-release.apk`
   (или просто перекинь APK на телефон). При запуске дай «Полный доступ к файлам».
2. **Яндекс**: Сервисы → Войти → открой ya.ru/device, введи код. Затем «Синхронизировать» и «Новые версии?».
   Это единственная часть, которую я не мог проверить вживую (нужен твой аккаунт) — если что-то
   упадёт, пришли текст ошибки из строки статуса.
3. **YouTube на телефоне**: если YouTube доступен только через VPN — включи VPN, либо укажи прокси
   в Настройки → Сеть.
4. **Десктоп**: `./gradlew :desktop:run` — звук там ночью не проверял.
5. Переименовать папку проекта: `mv ~/Projects/xvin_music_player ~/Projects/palimpsest` (после выхода из этой сессии).
